## 0.4.0 改了什么

### 编码修正（用户决定）

**彳 对应 R 键。** 部件「彳」的名称改为「人旁」，拼音首字母 r。

**衍 改用三件拆分。** 拆分来源改为 cjkvi-ids 的 ⿲彳氵亍，三个部件分别是彳(r)、氵(s)、亍(c)。原来走 hanzi-dictionary 的插入式拆法（行＋氵），拿到的字母不可猜。

### 新功能：米字格拆字窗口（学习模式）

选字落字后自动弹出一个小窗口，显示：
- 该字的米字格（背景参考线）和大字
- 结构类型（左右 / 上下 / 包围 / 独体……）
- 每个部件的字符、名称、完整带调拼音、对应键

窗口不抢焦点，可拖动，右键或点关闭按钮隐藏。

**此功能只过了 CI 的 MSVC 编译，没有在真机上验过。**

### 其他

- Python 解码器自检同步修正（henmazzrm 在 0.3.0 码表下整串匹配，无尾巴）

## 重要提醒

**这个安装包没有代码签名。** SmartScreen 会拦：点「更多信息」→「仍要运行」。

核对 SHA-256（PowerShell）：

```
Get-FileHash .\ZuxiaSetup-0.4.0.exe -Algorithm SHA256
```

## 装之前

先关掉微信、Word、浏览器。装完在任务栏切到「足下」。

老用户：`%LOCALAPPDATA%\Zuxia\设置.txt` 里「最小宽度」改成 120（0.3.0 起默认已是 120，只有从更早版本升级才需要手改）。

## 出问题了怎么说

附 `%LOCALAPPDATA%\Zuxia\zuxia.log`（只记事件，不记打过的字）。
