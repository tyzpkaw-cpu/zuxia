## 重要提醒

**这个安装包没有代码签名。** Windows 会弹「已阻止此应用」或者 SmartScreen 警告，这是预期的，不是安装包坏了。你可以：

- 点「更多信息」→「仍要运行」，或者
- 用下面的 SHA-256 自己核对，或者
- **不装，直接从源码自己编一份** —— fork 仓库跑一次 Actions 就有。这是最稳的做法

核对办法（PowerShell，整块复制粘贴）：

```
Get-FileHash .\ZuxiaSetup-0.2.0.exe -Algorithm SHA256
```

把结果和这次发布里的 `ZuxiaSetup-*.exe.sha256` 比一下。

## 装之前

**先关掉微信、Word、浏览器这些会用到输入法的程序。** 它们会把旧版 DLL 一直挂在自己进程里，不关就装了个新的也用着旧的，看到的现象会对不上。

装完在任务栏的输入法里切到「足下」。

## 怎么打字

一个词的码是三段拼接、逐位左对齐：**全拼 + 逐位结构 + 逐位部件**。

```
苏瑶  ->  suyao  +  sz  +  cw
          全拼      结构    部件
```

苏 = `su` + `s`（上下结构）+ `c`（草字头）
瑶 = `yao` + `z`（左右结构）+ `w`（王）

结构位五个：`z` 左右、`s` 上下、`b` 包围、`d` 独体、`p` 其他。
部件位是那个部件名字的拼音首字母。

只打全拼也能出字，结构位和部件位是**要精确定位时才加**——打得越满，候选越唯一。

几个可以直接试的：

| 打什么 | 出什么 |
|---|---|
| `qingzs` | 清 |
| `chud` | 出 |
| `hengz` | 衡 |
| `suyaoszcw` | 苏瑶 |
| `woxiangwen` | 我想问 |
| `xuancibz` | 选词 |
| `yangzhipengzszmsp` | 杨志鹏（词库里没有这个词，是现算出来的） |

## 最想知道的

1. 这套规则**好不好学**、**好不好猜**。猜不中的结构位请具体说是哪个字
2. 有没有**丢字**：打过的键没进去，或者选了候选之后剩下的码不见了
3. 有没有崩溃，或者某个程序里不好用（尤其是 Office、浏览器、微信、终端）
4. 打完中文标点之后还是不是中文；Shift＋9 出的是不是「（」

## 出问题了怎么说

请附上 `%LOCALAPPDATA%\Zuxia\zuxia.log`。它**只记事件，不记你打了什么字** —— 打过的码、选过的候选、落下的文本，一个字都不在里面。

文件资源管理器地址栏里粘这个就能找到：

```
%LOCALAPPDATA%\Zuxia
```

## 卸载

控制面板（设置 → 应用 → 已安装的应用）里正常卸载即可，或者直接跑安装目录里的
`ZuxiaUninstall.exe`。

卸载默认**留下** `%LOCALAPPDATA%\Zuxia`（约 15 MB：用户词典、回流表、日志、设置）。
这样重装之后调频和自造词还在。要彻底清干净，卸载完手动删掉那个文件夹。
