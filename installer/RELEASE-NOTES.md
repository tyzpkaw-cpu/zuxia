足下输入法 —— 试用版。给审核与试打字用，不是正式发布。

## 0.4.3 改了什么

只修一件事：**拆字窗拖不到另一块屏幕上。**

两块屏幕的缩放比例不一样时（比如笔记本 150%、外接显示器 100%），拆字窗一拖过两块屏的交界，就被拽回原来那块屏。原因：窗口换到另一种缩放的屏上时，Windows 会通知它「DPI 变了」，拆字窗一收到就按拖动之前的位置重新排版。现在：

- 拖动途中不重排，窗口一路跟着鼠标走，哪块屏都能去
- 放手时按那块屏的缩放重新排版（字号跟着那块屏走，所以窗口大小会变一下）
- 跨在两块屏的交界上放手，窗口整个收进占得多的那一块
- 记住的位置改成「哪块屏 ＋ 在屏上的比例」：各个程序里的拆字窗都出现在同一个地方。以前两块屏缩放不同时，有的程序会把记住的位置认偏，或者退回主屏右上角

这一处同样只过了编译，没有在真机的双屏上验过。

另外，仓库里加了 `scripts/刷新足下输入法.cmd`：装完新版双击它，它会找出还在用旧版输入法的程序，问过你之后关掉再重新打开，不用重启电脑。

0.4.2 的说明照旧留在下面。

## 0.4.2 改了什么

0.4.1 试用时反馈了三个问题，这一版逐个修；另外加了日期与农历。

**一、「揽月」打不出来。** 两个原因叠在一起，都修了：

- 「月」是独体字，0.4.1 只认它笔画树上的碎片（冂、二）当部件，按「看见一个月」打 `y` 不认。现在**独体字可以整字作部件**：结构码 `d` 之后，用这个字自己读音的首字母——`yuedy` → 月。拆不出部件的字（非、竹、毋……）同样适用。一共 265 个字。
- `lanyuezd` 被 Rime 读成「蓝＋刖」，连同一串前缀词占满了一页，列式解码器一个位置都分不到。现在码一旦打进了结构／部件那几位、而 Rime 的首选对不上，解码结果就排到最前（这一页给 Rime 留最多三位）。只打全拼时照旧，Rime 的首选一个字不动。

现在 `lanyuezd`、`lanyuezdly`（揽 取「览」l，月 整字 y）、`lanyuezdlj`（月 取「冂」j）都是揽月排第一。

**二、拆字窗一拖就消失、不能调大小、词组最后一行被截掉。** 拆字窗整个重写了：

- 不抢焦点：点它、拖它，打字的光标都留在原来的文档里
- 按住窗口任意处都能拖；拖边或拖角等比缩放（字号跟着变），滚轮也能缩放，双击标题条复原
- 按实际文字量排版，词组里每个字都完整显示（最多 8 个字）
- 落字之后仍显示刚上屏的字，方便对照；点 × 或右键，这次组字里不再弹出，下次组字自动回来
- 切到西文、关掉学习模式、焦点离开输入框、切到别的程序时自动隐藏
- 记住位置和大小，下次在原处出现；第一次出现在屏幕右上角

**三、日期与农历。** 打 `dt` 出日期时间（11 条：年月日、2026-10-01 这种写法、星期、时分、带秒、ISO 8601……），打 `nl` 出今天的农历（八月廿一、农历八月廿一、丙午马年八月廿一、干支、下一个节气；当天是节日或节气时多一条）。后面带一个冒号 `dt:`、`nl:` 也行。农历覆盖 1900—2100 年，每一天都和寿星天文历（sxtwl）核对过。`dt`、`nl` 不是任何字的码，不会挡住正常打字。

**顺手修的：混排时选字。** 解码器的候选和 Rime 的候选排在同一页时，数字键、空格、上下键都按「这个位置上是谁」来选，不会出现按 3 选到第 4 个。

**代价要如实说。** 整字作部件给一级部件码多加了一批会和别的字撞车的码：只打一个部件时的首选率 88.08%→87.91%（少 0.17 个百分点），总击键 3.81→3.82 键／字；打两个、三个部件时不变（96.06%、97.97%）。原来的码一条不少：0.4.1 的 274,327 条全在，新增 252 条。这条放宽可以撤回，撤回后码表就回到 0.4.1 的样子。

**这一版的改动只过了 CI**（编译、85 条引擎断言、农历逐日核对），**没有在真机上验过**。拆字窗尤其如此——窗口那一层没有任何自动化测试碰得到。请按下面的表试，对不上就提 Issue。

## 怎么打字

一个词的码是三段拼接、逐位左对齐：**全拼 + 逐位结构 + 逐位部件**。

```
苏瑶  ->  suyao  +  sz  +  cw
          全拼      结构    部件
```

苏 = `su` + `s`（上下结构）+ `c`（草字头）
瑶 = `yao` + `z`（左右结构）+ `w`（王）

结构位五个：`z` 左右、`s` 上下、`b` 包围、`d` 独体、`p` 其他。
部件位是那个部件名字的拼音首字母；独体字还可以用它自己读音的首字母。

只打全拼也能出字，结构位和部件位是**要精确定位时才加**——打得越满，候选越少。

几个可以直接试的（**0.4.2 新增**的标了出来）：

| 打什么 | 出什么 |
|---|---|
| `qingzs` | 清情碃 |
| `chud` | 出 |
| `yanzss` | 衍（3 个候选） |
| `fuzrfc` | 傅俯蝮 |
| `chaozsry` | 朝（唯一） |
| `shoubb` | 瘦（唯一） |
| `haostk` | 毫（唯一） |
| `shuzml` | 梳（唯一） |
| `yuedj` | 月（唯一） |
| `yuedy` | 月（排第一；**0.4.2 新增**，整字作部件） |
| `lanyuezdly` | 揽月（排第一；**0.4.2 新增**） |
| `suyaoszcw` | 苏耀（首选） |
| `suyaoszcwbf` | 苏瑶 |
| `woxiangwen` | 我想问 |
| `xuancibz` | 选词 |
| `yangzhipengzszmsp` | 杨志鹏（词库里没有这个词，是现算出来的） |
| `dt` | 今天的日期、星期、时间（**0.4.2 新增**） |
| `nl` | 今天的农历（**0.4.2 新增**） |

注意：毫有四个部件（亠 t、口 k、冖 b、毛 m），但一个码最多三个部件字母，所以没有 `haostkbm` 这条码。

## 拆字窗怎么试

1. 开始菜单搜「足下输入法设置」，打开「拆字窗口（学习模式）」
2. 打 `lanyuezdly`：拆字窗应显示「揽」「月」两个字，每个部件一行，最后一行不被截掉
3. 拖它、拖边角、滚轮、双击标题条：窗口不该消失，打字的光标不该跑到它身上
4. 按空格上屏：拆字窗应该还在，显示刚上屏的「揽月」
5. 再打一个字，点拆字窗的 ×：这次组字里它不再出来；落字后再打下一个字，它应该自动回来
6. 关掉它所在的程序、切到别的程序：它应该自己隐藏
7. 有两块屏幕的话：把它拖到另一块屏上放手，它应该留在那块屏上；再打字，它还在那里出现

## 最想知道的

1. 这套规则**好不好学**、**好不好猜**。猜不中的结构位请具体说是哪个字
2. **部件码现在够不够用**？有没有哪个字你想到的拆法还是打不出来？
3. **拆字窗**：上面 6 步哪一步对不上
4. 有没有**丢字**：打过的键没进去，或者选了候选之后剩下的码不见了
5. 有没有崩溃，或者某个程序里不好用（尤其是 Office、浏览器、微信、终端）

## 出问题了怎么说

请附上 `%LOCALAPPDATA%\Zuxia\zuxia.log`。它**只记事件，不记你打了什么字** —— 打过的码、选过的候选、落下的文本，一个字都不在里面。

文件资源管理器地址栏里粘这个就能找到：

```
%LOCALAPPDATA%\Zuxia
```

## 卸载

控制面板（设置 → 应用 → 已安装的应用）里正常卸载即可，或者直接跑安装目录里的
`ZuxiaUninstall.exe`。
