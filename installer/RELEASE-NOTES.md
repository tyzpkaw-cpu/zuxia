足下输入法 —— 试用版。给审核与试打字用，不是正式发布。

## 0.4.1 改了什么

这一版动了三件事，它们是一起上线的，拆开任何一件都会出问题。

**第一件：部件名称改用国标。** 部件名字表并入了 GF 0014—2009《现代常用字部件及部件名称规范》里的国标名称（宝盖、草字头、病字框、倒八、私字边……）。并入方式是追加：你原来记住的人工名称优先，国标名称补在后面，部件自身的读音留在最后兜底。这跟结构码以 GF 0013—2009 为准是同一家族的标准。

**第二件：没名称的部件再往里拆一层。** 顶层部件本身一定保留，只是把那些没有名字的部件再拆开一层，让它们也能被猜出来。

**第三件：一个码最多带的部件字母从两个放宽到三个。** 顺序仍然不限。

**你已经记住的码一条都没失效。** 0.2.0 的 66,505 条码一条都没丢，`data-tools/audit_zuxia.py` 不存快照，而是现场用 0.2.0 的算法（只取顶层部件、只认人工名称表、最多两位）重算一遍再比对。

**规模。** 单字码表从 66,505 行 / 1.0 MB 涨到 **275,268 行 / 4.4 MB**（8183 个字，平均每字 33.64 个码）；词码从 421,131 行 / 12.2 MB 涨到 619,357 行 / 18.6 MB；列式解码器的数据从 3.0 MB 涨到 3.39 MB。**Rime 首次部署会因此变慢，但没有在真机上量过——这一项未经验证。**

**代价要如实说：短码的候选变多了。** 一级和二级部件码的首选率都退了（89.78%→88.13%，98.16%→96.08%），平均同码候选变多（4.16→4.79，1.43→2.00）。原因是「穷尽」本身：别条路多了，每条路上的字也就多了。总击键从 3.76 涨到 3.81（+1.3%），等于把原先两键就到 98% 的位置往后推了一键。换来的是打满唯一性从 82.45% 升到 85.03%，以及作者原先打不出来的那些拆法现在都有码。这是一次明确的取舍，不是纯改进。

## 怎么打字

一个词的码是三段拼接、逐位左对齐：**全拼 + 逐位结构 + 逐位部件**。

```
苏瑶  ->  suyao  +  sz  +  cw
          全拼      结构    部件
```

苏 = `su` + `s`（上下结构）+ `c`（草字头）
瑶 = `yao` + `z`（左右结构）+ `w`（王）

结构位五个：`z` 左右、`s` 上下、`b` 包围、`d` 独体、`p` 其他。
部件位是那个部件名字的拼音首字母。

只打全拼也能出字，结构位和部件位是**要精确定位时才加**——打得越满，候选越唯一。

几个可以直接试的：

| 打什么 | 出什么 |
|---|---|
| `qingzs` | 清情碃 |
| `chud` | 出 |
| `yanzss` | 衍（3 个候选） |
| `fuzrfc` | 傅俯蝮 |
| `chaozsry` | 朝（唯一） |
| `shoubb` | 瘦（唯一） |
| `haostk` | 毫（唯一） |
| `shuzml` | 梳（唯一） |
| `yuedj` | 月（唯一） |
| `suyaoszcw` | 苏耀（首选） |
| `suyaoszcwbf` | 苏瑶 |
| `woxiangwen` | 我想问 |
| `xuancibz` | 选词 |
| `yangzhipengzszmsp` | 杨志鹏（词库里没有这个词，是现算出来的） |

注意：毫有四个部件（亠 t、口 k、冖 b、毛 m），但一个码最多三个部件字母，所以没有 `haostkbm` 这条码。

## 三个已修的 bug

**Caps Lock 不生效。** 中文模式下 Caps Lock 亮着且没在组字时，字母直通应用程序，直接出大写英文。schema 里的 `ascii_composer.good_old_caps_lock` 对足下从来不生效，因为中/西切换是 TSF 层的预留键，Caps Lock 根本不会交给 librime。现在修好了。

**组字打一半按回车。** 原来把原始码串当英文落进文档（librime express_editor 的默认行为），现在改成放弃这次组字、什么都不落。打英文走中/西切换。这同时是「揽月……部件码 ry 也会落入文本」的根因。

**候选窗宽度不会变。** 算法没错，是下限 `min_width` 默认 220 太宽，九个单字候选的最长一行远不到 220，所以始终卡在下限。默认降到 120，并且同一次组字里只长不缩。

**已经有设置文件的用户注意：文件里存的还是 220，要自己把「最小宽度」那一行改成 120。** 打开设置文件，找到「最小宽度」那一行，把 220 改成 120，保存即可。

**本节三项修复只过了 CI 的 MSVC 编译，没有在真机上验过。** 实际行为与此处描述不一致请提 Issue。

## 出问题了怎么说

请附上 `%LOCALAPPDATA%\Zuxia\zuxia.log`。它**只记事件，不记你打了什么字** —— 打过的码、选过的候选、落下的文本，一个字都不在里面。

文件资源管理器地址栏里粘这个就能找到：

```
%LOCALAPPDATA%\Zuxia
```

## 卸载

控制面板（设置 → 应用 → 已安装的应用）里正常卸载即可，或者直接跑安装目录里的
`ZuxiaUninstall.exe`。

卸载默认**留下** `%LOCALAPPDATA%\Zuxia`（约 15 MB：用户词典、回流表、日志、设置）。
这样重装之后调频和自造词还在。要彻底清干净，卸载完手动删掉那个文件夹。
